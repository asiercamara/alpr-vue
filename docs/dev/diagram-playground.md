# DiagramPresenter Playground

Use this page to validate `DiagramPresenter` behavior before copying a snippet into the docs. It now includes:

- a **live prop editor** for the main preview
- **feature presets** for phase navigation, spotlight, and neon mode
- a **showcase gallery** with preconfigured examples
- a **story-mode demo** chained through `play-complete`
- quick access to **SVG export**, modal shortcuts, zoom-to-node, and scrubber testing

> **Note:** This page is for contributors editing the documentation. It is not part of the public-facing help docs.

## What to verify here

1. Use the left panel to build the exact configuration you want.
2. Double-click any diagram to open the fullscreen modal and test keyboard shortcuts.
3. Use the **Feature presets** section to jump straight to spotlight / phaseNav / neon behaviors.
4. Use the **Story mode pattern** section to verify chained presenters without adding new component API.
5. Copy the generated snippet when the preview matches the intended docs example.
